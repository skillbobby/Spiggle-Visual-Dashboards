More of the canvas

Features

Everything you need to ship a dashboard

No separate data warehouse. Charts read the Eloquent models that already hold your records.

Canvas

Drag, resize, snap

Cards snap into the nearest gap. Drop one on another to stack it in front or behind. Layouts feel intentional without pixel-pushing.

Charts

Gallery of visuals

KPI card, table, line, bar, column, pie, donut, stacked, funnel, and radial gauge. Pick the visual that matches the question.

Data

Live models

Bind category and measure fields from Eloquent models, including related names. Row count is available when you just need a total.

Share

Public link

Optional anonymous access at /visual-dashboards/{id}/{slug}. Signed-in viewers with the right role can always open it.

Access

Viewer roles

Optional Spatie or Shield allowlist for signed-in viewing, including per dashlet. Works fine if neither package is installed.

Panel

One sidebar item

Visual Dashboards opens the dashboard list. No extra clutter in the panel navigation.

Install

Up and running in minutes

Require the package and migrate:

composer require spiggle/visual-dashboards
php artisan migrate

Register the plugin on your Filament panel:

use Spiggle\VisualDashboards\Filament\VisualDashboardsPlugin;

$panel->plugin(VisualDashboardsPlugin::make());

Check the install:

php artisan visual-dashboards:verify
How it works

From blank canvas to shareable page

1

Create a dashboard

Open Visual Dashboards, name a new board, and open the canvas.

2

Insert a visual

Pick a chart. Bars work well for comparing categories. Bind the model, category field, and measure.

3

Add a headline

Drop a KPI card the same way when the page needs a single number at the top.

4

Arrange the canvas

Drag by the header. Cards snap into gaps. Drop one on another to stack it.

5

Publish

Turn on Public link in dashboard settings. Anyone with the URL can view it; signed-in allowed roles can always open it.

6

Share

Copy the share URL. The page stays live against the records already in your app.
